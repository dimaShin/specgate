# specgate Service Provider Addendum (Commercial Terms Offer)

This document is **not** an additional restriction to AGPL rights.

The code in this repository is licensed under AGPL-3.0. Any party may use those AGPL rights as granted by that license.

This addendum defines an optional **separate commercial agreement path** for organizations that want to offer `specgate` as a managed/hosted service.

## Managed service policy

If you offer a managed/hosted service substantially powered by `specgate`, maintainers welcome a direct commercial conversation for long-term partnership terms.

Community contributions remain welcome but are optional and handled through the normal open-source workflow.

## Contact

To request commercial terms for managed service usage, open an issue in this repository to start the process.

## Important legal note

Only a signed commercial agreement creates contractual obligations beyond AGPL.
This addendum is a project policy and commercial-terms offer framework.
